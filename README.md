🎙️ AI Voice Meeting Analyzer

An AI-powered meeting analysis application that converts recorded conversations into text and generates structured Minutes of Meeting (MOM).

The project is designed to help users understand meeting conversations by extracting important information such as the summary, agenda, discussion points, tasks, deadlines, decisions, testing plans, and next steps.

🚀 Features
🎤 Record a meeting through the browser
📁 Upload recorded audio/media files
📝 Convert speech into text
🤖 Analyze meeting conversations using AI
📋 Generate structured Minutes of Meeting (MOM)
🎯 Identify the meeting agenda
💬 Extract discussion points
✅ Identify tasks and responsibilities
📅 Identify deadlines
🧠 Extract important decisions
🧪 Identify testing plans
🔜 Generate next steps
🌐 Web-based user interface
🔌 API-based backend
📄 Generate meeting analysis output
